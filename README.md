# SALY Demo

SALY is desktop tax software for preparers, built by a practicing CPA at Noblesville Tax
Management, LLC. The whole return lives on your own computer, so every number updates the moment
you type it, and client returns never leave your office.

This page holds the **demo** downloads. More about SALY: [ntmcpa.com/saly](https://ntmcpa.com/saly)

## Download

Get the newest version from **[Releases](../../releases/latest)**:

- **Mac** (Apple silicon, M1 or newer): `SALY-Demo-Mac-<version>.zip`
- **Windows** 10 or 11, 64-bit: `SALY-Demo-Windows-<version>.zip`
- **How to open it**: `How-to-open-SALY-Demo.pdf`

## About the demo

- 316 fictional returns to open, change and print (individuals, S corporations, partnerships,
  estates and trusts), and you can start new ones. Every name, number and address in it is made
  up.
- **Please don't type in real people's information.** Every printed page says
  "DEMO - NOT FOR FILING": nothing from it can be filed.
- It works through **December 31, 2026**, then opens to a message saying the demo has ended.
- It needs no account and sends nothing over the internet.

## Opening it

- **Mac:** unzip, drag SALY Demo to Applications, and double-click it. The Mac copy is signed and
  checked by Apple; the first time, click **Open**.
- **Windows:** unzip and run the installer. Until the Windows copy is signed, a
  "Windows protected your PC" box may come up: choose **More info**, then **Run anyway**.
